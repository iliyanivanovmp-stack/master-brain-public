# X Post Writing Frameworks

Hook patterns, body shapes, CTA rules, voice register, and slop scrub for X (Twitter) posts. Applies to all 11 post types in the x-post-writer system and to any manual tweet drafting.

---

## Post Types

### Group 1: Conversion-Focused

| Type | Purpose | Length | CTA |
|---|---|---|---|
| `case_study` | Narrative transformation story for B2B founders | 250-350w | KEYWORD gate |
| `contrarian_take` | "Everyone else is wrong" + named concept | 150-220w | Soft or none |
| `system_breakdown` | How a specific AI system works, with real tools | 200-280w | KEYWORD gate |
| `ai_income` | Accessible income opportunity with AI | 130-200w | KEYWORD gate |
| `lead_magnet` | Ultra-short viral post for max reach | 40-75w | KEYWORD gate |

### Group 2: Build-in-Public / Skill-Based

| Type | Purpose | Length | CTA |
|---|---|---|---|
| `milestone` | Announce a hard result, no fanfare | 60-120w | None |
| `lesson` | Numbered lessons backed by real volume | 80-180w solo / 4-6 tweets thread | None (solo) / follow gate (thread) |
| `hot_take` | Quoted cliché + data counter, designed to be quote-tweeted | 60-140w | None |
| `build_in_public` | Quick metric update or one-line self-roast | 40-120w | None |
| `ip_giveaway` | Give away a named asset behind a follow gate | 80-140w solo / 4-7 tweets thread | KEYWORD gate (always) |
| `self_roast` | Specific failure or wasted effort, played for laughs | 40-100w | None |

## Hook Patterns (H1-H8)

Pick ONE hook per post. Vary across posts.

| Code | Pattern | Example |
|---|---|---|
| H1 | Bare metric, no preamble | "Gojiberry AI just hit $2M ARR." |
| H2 | Volume credential + costly mistake | "After 3,200+ outbound campaigns at ColdIQ, the most expensive mistake I still see..." |
| H3 | Year-over-year decline/shift stat | "Cold emails needed for one positive reply: 2023: ~120 / 2024: ~200 / 2025: ~430" |
| H4 | Self-roast comparison | "spent 3 weeks building a targeting system. AI agent did it in 15 min" |
| H5 | Quoted strawman + receipts | "'cold email is dead' meanwhile us: $30k → $550k months" |
| H6 | Failure stack → outcome | "Got fired from 4 jobs. Failed at 7 startups. Lost $40K. Then..." |
| H7 | IP-giveaway hook | "I'm giving away the exact prompt sequence we use to generate 40 ad creatives in 20 min." |
| H8 | Mock-formal industry obit | "i regret to inform you that cold outbound has been solved and most agencies are still billing $8K/month for it" |

**Hooks to never use on X (LinkedIn imports):**
- "Excited to announce...", "Thrilled to share...", "Big news!"
- "Here are 7 lessons from..." (as solo tweet)
- "Most people think X. They're wrong."
- Any hook that needs "1/" because the actual idea hasn't started

## Body Shapes — Solo (S1-S5)

**S1 · Bare metric + 1-line context**
Hook: H1 bare number → 1 sentence of context. Nothing else.

**S2 · Number stack with opinion close**
3-5 data points on separate lines. Close with 1 opinion line that draws the conclusion.
> "We turned 24 employees into LinkedIn influencers in 90 days.
> 581 posts. 43,473 reactions. 28,130 comments. 27 new clients worth $153K in MRR."

**S3 · Quoted strawman + > counter bullets**
Open with the cliché in quotes. Then `>` lines demolishing it with specifics.
> "'services don't scale'
> > chases the $10k software budget inside companies
> > watches openai kill the feature in 3 months"

**S4 · Single-line shitpost**
The entire post = the hook. 1 line only. Lowercase. No CTA.

**S5 · Numbered listicle**
Title line (credential or thesis). Then 3-5 numbered items, each 1-2 lines max.

---

## Body Shapes — Thread (T1-T3)

**T1 · Tactical breakdown**
Tweet 1: hook (must work standalone). Tweets 2-N: numbered steps, 1 per tweet. Last tweet: CTA.

**T2 · Story thread**
Tweet 1: hook = scar or failure moment. Tweets 2-N: context → mistake → shift → lesson. Last tweet: lesson + soft CTA.

**T3 · List thread**
Tweet 1: hook = "X mistakes I see at $Y ARR companies". Each following tweet = 1 item + one-line example. Last tweet: giveaway CTA or follow CTA.

## Voice Register

**Lowercase mode:** self-roasts, shitposts, one-line dunks, quick reactions, "phone-typing" feel.

**Sentence case mode:** milestones, hard data, authority takes, most thread hooks.

Mix is normal — don't force uniformity within a thread.

Rules for all modes:
- First person: "I built", "I run", "I made", "I helped"
- Address one reader: "you", never "people", "founders", "entrepreneurs" generically
- State as fact, no hedging: never "might", "could potentially", "tends to"
- Concrete beats abstract: "saved 14 hours a week" beats "improved efficiency"
- Active verbs: build, ship, drop, spin up
- Plain English: "use" not "leverage", "help" not "empower"
- Numerals always: "3x", "$2M", "23,000,000 sends" — never "three times" or "two million"
- Numbers always specific: "$37,017" not "$37K", "69%" not "most"

## CTA Rules

**Default: no CTA.** Most posts don't need one. Forced CTAs are the strongest LinkedIn-import tell.

| CTA | When used | Format |
|---|---|---|
| CTA-A | ip_giveaway, lead_magnet (standard) | `Comment "[KEYWORD]" and I'll send it over. must be following to DM.` |
| CTA-B | lead_magnet (urgency variant) | `Comment "[KEYWORD]" to get it. FREE for 48 hrs. must follow + retweet.` |
| CTA-C | lesson thread, ip_giveaway thread | `Follow @handle for more on [topic].` |

**KEYWORD** is always short ALL CAPS: BLUEPRINT, AUDIT, SYSTEM, MAP, GUIDE, FACTORY, PLAYBOOK.

**Banned closers:**
"Agree?", "Thoughts?", "What do you think?", "Tag someone who needs this.", "Save this for later.", "Like and follow for more.", "Hope this helps."

## Slop Scrub (Mandatory Before Publishing)

Any hit → rewrite the sentence.

**Banned phrases:**
game changer, in the age of AI, the future is here, AI is changing everything, here's the truth, let me be real, nobody talks about this, this is what separates, most people don't know, deep dive, delve, navigate the landscape, unlock the potential, unlock the power, move the needle, stay ahead of the curve, cutting-edge, state-of-the-art, seamless, world-class, leverage (verb), synergy, transformative, innovative, holistic, comprehensive, groundbreaking, robust, streamline, hope this helps, let that sink in, read that again, spoiler:, plot twist:, excited to announce, thrilled to share, big news, buckle up, here's the kicker, here's the catch, here's the thing, furthermore, moreover, additionally, that said (as opener), importantly (as opener), ultimately (as closer), a testament to, it's important to note, at its core, embark on, foster (as verb), drive impact, couldn't be more proud, trust the process, your network is your net worth, i'm humbled to announce, dive into.

**Banned structural slop:**
- 3+ negation pivots in one post ("not X, not Y, not Z — it's W")
- Tricolons of parallel verbs ("build, scale, and grow")
- Throat-clearing transitions: "Furthermore," "Moreover," "Additionally," "That said,"
- Bold/italic Unicode tricks (`𝗯𝗼𝗹𝗱`)
- Keycap emoji as headers (1️⃣ 2️⃣) — use plain `1.` or `1)`
- Emoji as bullet markers (🚀 ✨ 💡) — inline emoji only, max 1 per tweet

**Banned openers:**
- "In the last X months AI changed..."
- "Most people are still..."
- "Here's the thing:"
- "Let me show you"
- "Thread:"
- Any opener ending with colon + one-line tease: "Here's what I learned:"

**Single-word replacements:**
leverage→use, utilize→use, empower→help, seamless→smooth, optimize→improve, delve→look into, dive→go into, foster→build, elevate→raise, transform→change, revolutionize→change, holistic→full, pivotal→key.

## Output Format (for manual drafting)

For each draft, show:
- **Format:** solo tweet / thread / list thread
- **Char count** (solo): `247 / 280`
- **Hook pattern:** e.g. "H4 · self-roast comparison"
- **Body shape:** e.g. "S2 · number stack with line breaks"
- **Voice register:** lowercase / sentence case / mixed
- **Slop scrub:** "0 hits" or list flags caught + how rewritten
- **Why it works (X-specific):** 1-2 sentences on what makes this read as native X
- **One alt hook** the user can swap in

Default output: 1 solo tweet + 1 alt solo from a different hook pattern. If brief asks for thread, deliver thread + 1 solo variant.
