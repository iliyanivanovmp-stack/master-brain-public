01 — The mental model

Three buckets. Three different jobs.

Most "memory frameworks" try to do everything in one place. That's the wrong question. There are three distinct jobs — each goes to its natural home.

03 — The skill

The Strategy & Awareness skill operates in four modes.

It auto-fires when conversation surfaces strategic substance. You never have to think about it — Claude routes the moment to the right section.

MODE 01

Setup

First run. Six clarifying questions. Generates your starter strategy file from the template.

Run my strategy setup.
MODE 02

Capture

Auto-fires when you mention something strategic. Reads file, picks the right section, appends a dated line.

Three customers asked for Slack today.
MODE 03

Reflect

When you're working on something, surfaces relevant existing strategy and any conflicts with your Don't-Do list.

Let's add a dashboard feature.
MODE 04

Query

You ask a strategic question. Returns the relevant section verbatim plus a 2-line synthesis.

What's my current pricing strategy?

05 — Get it running

Three steps. Two minutes.

The whole package lives at ~/Desktop/strategy-awareness/. Three steps to install it for yourself.

1

Copy the skill into Claude's skills directory

This is where Claude Code looks for global skills.

mkdir -p ~/.claude/skills/strategy-awareness cp ~/Desktop/strategy-awareness/SKILL.md ~/.claude/skills/strategy-awareness/
2

Open any Claude Code session and run setup

Type this and answer the six questions. Claude will create your starter strategy file.

Run my strategy setup.
3

That's it. Just talk to Claude.

From now on, when you mention strategic stuff in normal conversation, the skill captures it. To check what it knows, ask: "Show my strategy."
