## Card Types

- **Pure Skill** — Claude executes entirely in context using KB files. No external code needed.
- **Execution Card** — Requires running an external script/project. Card is a recipe pointing to it.
- **Hybrid** — Claude handles the knowledge/drafting phase, external script handles execution/publishing.
